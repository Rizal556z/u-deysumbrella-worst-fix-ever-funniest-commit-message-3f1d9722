# Worst Fix Ever: Funniest Commit Message

A single commit message for a bug fix that made everything worse, written by a pure-stdlib Python program for the make.fun bounty **Worst Fix Ever: Funniest Commit Message**.

> fix: stop the disk filling up by deleting the backups — disk is empty and so is our recovery plan

Run `python3 main.py` — it writes the commit message (one line, 97 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–100 characters, single line, no trailing newline).
